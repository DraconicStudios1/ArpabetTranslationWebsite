# ArpabetTranslationWebsite
Python Webserver Package for a basic Arpabet Translator

The Arpabet Translation Website is part of the BOSCO Assistant Project, which is an open-source python application being developed by the Draconic Technologies BOSCO division.

Input raw text, get an Arpabet translation.
pretty simple!
